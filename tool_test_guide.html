Direct MCP Smoke Test

This is the most exact command-line test in the repo right now. It checks the actual MCP server, without depending on the Bob UI.

1

Stay in the repo root

Make sure your terminal prompt is still inside /Users/bilolbekrayimov/games/IBM_hackathon.

2

Paste this exact smoke-test block into Terminal

Copy the whole block below, paste it into Terminal, then press Enter. 

node <<'NODE'
const { spawn } = require('node:child_process');
const fs = require('node:fs');
const path = require('node:path');

function callMcp(method, params, env = {}) {
  return new Promise((resolve, reject) => {
    const child = spawn('node', [path.join(process.cwd(), 'packages/mcp-server/dist/index.js')], {
      stdio: ['pipe', 'pipe', 'pipe'],
      env: { ...process.env, ...env }
    });
    let stdout = '';
    let stderr = '';
    let settled = false;

    child.stdout.on('data', (chunk) => {
      stdout += chunk.toString();
      try {
        const parsed = JSON.parse(stdout);
        if (!settled) {
          settled = true;
          resolve(parsed);
          child.kill();
        }
      } catch {}
    });

    child.stderr.on('data', (chunk) => {
      stderr += chunk.toString();
    });

    child.on('error', (error) => {
      if (!settled) {
        settled = true;
        reject(error);
      }
    });

    child.on('close', () => {
      if (!settled) {
        reject(new Error(`Could not parse MCP response.\nSTDOUT:\n${stdout}\nSTDERR:\n${stderr}`));
      }
    });

    child.stdin.write(JSON.stringify({ jsonrpc: '2.0', id: 1, method, params }) + '\n');
    child.stdin.end();
  });
}

(async () => {
  const repoRoot = process.cwd();
  const list = await callMcp('tools/list');
  console.log('Tool count:', list.result.tools.length);

  const discover = await callMcp('tools/call', {
    name: 'discover_repo_scope',
    arguments: { repoRoot }
  });
  console.log('discover_repo_scope:', discover.result.content[0].text);

  const report = JSON.parse(fs.readFileSync('fixtures/contracts/reports/valid-report.json', 'utf8'));
  const reportId = `guide-${new Date().toISOString().replace(/[-:]/g, '').replace(/\.\d{3}Z$/, 'Z')}`;
  report.reportId = reportId;
  report.createdAt = new Date().toISOString();
  report.repoRoot = repoRoot;

  const save = await callMcp('tools/call', {
    name: 'save_modernization_report',
    arguments: { report }
  });
  console.log('save_modernization_report:', save.result.content[0].text);

  const open = await callMcp('tools/call', {
    name: 'open_report_viewer',
    arguments: { reportPath: 'reports/latest/report.json', autoOpenViewer: false }
  }, { VIEWER_PORT: '4557' });
  console.log('open_report_viewer:', open.result.content[0].text);
})();
NODE

sed -n '1,80p' reports/index.json

Pass condition: the manifest, latest report, and history folder all show fresh saved data.

Artifacts To Check

reports/index.json

The manifest used by the viewer. It should contain latestReportPath and a non-empty history array after successful saves.

reports/latest/report.json

The latest saved report. The live viewer reads this through the manifest.

reports/history/

History reports. A successful save should add a new JSON file whose name matches the report ID.

What a valid generated report ID looks like The current schema accepts IDs like guide-20260516T102714Z or 20260516T102714Z. It does not accept IDs like test-1778920405745.

Known Caveats

1

The repo completion script is slightly stale

scripts/test-dev1-completion.ts still creates a save-report ID using the old test-<epoch> format. If you run it unchanged, its save-report test will fail even though the actual save tool works with the current schema-compliant ID format.

2

Port conflicts are normal during local testing

If you get EADDRINUSE, the port is already occupied. Pick another one with VIEWER_PORT=4556, VIEWER_PORT=4557, or another free port.

3

The direct MCP smoke test writes report artifacts

That is expected. The save tool is supposed to write reports/latest/report.json, reports/history/<reportId>.json, and the manifest.
